# Sadeel Dental Care

مهم جدًا:
- لا تنشئ مجرد نموذج أولي أو Mockup.
- أنشئ الموقع فعليًا بكل الصفحات والأقسام والأزرار والتجاوب.
- تأكد أن المشروع يعمل بدون أخطاء TypeScript أو React أو Console.
- لا تترك أي أزرار غير عاملة.
- لا تستخدم نصوص Lorem Ipsum.
- لا تضف معلومات طبية أو شهادات أو تخصصات غير مذكورة في البيانات التي سأعطيك إياها.
